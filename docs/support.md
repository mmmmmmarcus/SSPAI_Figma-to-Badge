# Support status

| Feature | Status |
|---|---|
| Headless Blender, GLB + USDZ | Included; real demo exports and import validation |
| Gold and silver PBR | Included; original demo recipes for both |
| Native Figma color/gray PNG delivery | Supported by plan helper; original bytes copied |
| Dedicated third texture frame | Required by generic three-frame helper |
| Reusable templates | Explicit mappings; no shape recognition by names |
| Multiple geometry/texture layers | Engine supports direct recipes; generic plan helper handles one each |
| Arbitrary silhouettes / holes / sharp concave turns | Experimental; needs new template and per-shape validation |
| Lights/cameras | Excluded by default; Skill requires both formats without them |
| STEP/STP or manufacturing solids | Not supported |
| 3D preview PNG | Not generated by this Skill |

The private workflow that motivated this project tested an irregular AdventureX-shaped badge. Its sharp-turn round surface checks did not meet the calibrated production tolerances. Its artwork, templates, outputs and Figma references are **not distributed here**; that trial is not a public supported profile. Silver is a material preset and does not make arbitrary silver geometry automatically supported.

The original calibrated production shapes are also private. This repository publishes the reusable engine, workflow and original demo, not those assets. A new user's production design needs its own mapping and native viewer review. Successful file export alone does not prove absence of reflection seams or AR-device acceptance.
